# BLACKOUT — AI Escape Room (QAIRU Final Project 2026)

Бірінші жақтан көрінетін 3D ойын. Күзетші сені іздейді, сен терминалдардан шарттар жинап, 4 таңбалы кодты шешесің.
Жоба №10 (AI Escape Room), 6 деңгей, қазақ тілінде.

## Қолданылған AI тақырыптары (кемінде 3 түрлі апта)
| Апта | Тақырып | Ойында қайда | Python файлы | JS (ойын ішінде) |
|---|---|---|---|---|
| 2 | A* | күзетші саған ең қысқа жолмен келеді | `ai/astar.py` | `astar` |
| 3 | CSP (backtracking) | код цифрларын шарттар бойынша табу | `ai/csp.py` | `mkClues`, `solve` |
| 7 | HMM / Байес сүзгісі | күзетші сенің орныңды ықтималдықпен бағалайды | `ai/hmm.py` | `bPredict`, `bUpdate` |

**Маңызды:** ойынның өзі JavaScript-те жазылған және браузерде жұмыс істейді (`static/blackout.html`).
`ai/` папкасындағы Python коды — сол алгоритмдердің Python нұсқасы: тесттер, демо және API осыған негізделген.

## Құрылым
```
app.py              Flask сервері: ойынды береді + API (/api/maze, /api/puzzle)
```

## Іске қосу (қадамдап)
1. Python 3.10+ орнатыңыз. Тексеру: `python --version`.
2. Zip-ті ашып, терминалды жоба папкасында ашыңыз.
3. Виртуалды орта жасаңыз:
   - Windows: `python -m venv .venv`, содан соң `.venv\Scripts\activate`
   - macOS/Linux: `python3 -m venv .venv`, содан соң `source .venv/bin/activate`
4. Кітапханаларды орнатыңыз: `pip install -r requirements.txt`
5. Тесттерді іске қосыңыз: `python -m pytest -q` (нәтиже: `9 passed`)
6. Демо: `python demo.py`
7. Ойын: `python app.py`, содан соң браузерде http://127.0.0.1:5000 ашыңыз (интернет керек — three.js желіден жүктеледі).
8. API демосы: екінші терминалда `python demo_client.py`

Python-сыз да болады: `static/blackout.html` файлын екі рет шертіп ашыңыз.

Басқару: WASD — жүру, тышқан — қарау, Shift — жүгіру (шу шығарады), E — әрекет, Tab — жасанды интеллект «миы».

# ТҮСІНДІРМЕ

## 1. Виртуалды орта (.venv) не үшін
`pip install flask` деп орнатсаң, кітапхана компьютердегі ортақ Python-ға түседі. Бір жобаға Flask 2, екіншісіне Flask 3 керек болса, қақтығыс шығады.
`python -m venv .venv` жоба ішінде жеке Python көшірмесін және кітапханалар үшін бос папка жасайды. `activate` терминалға `python` мен `pip`-ті осы папкадан алуды айтады.
Нәтижесінде бәрі тек осы жобаға орнатылады, жобаны өшіргенде ортасы да кетеді.
`requirements.txt` — қажет кітапханалар тізімі; `pip install -r` бәрін бірден орнатады, сондықтан тексеруші жобаны дәл осылай іске қосады.
`.venv` GitHub-қа салынбайды (ауыр, қайта жасалады), сондықтан `.gitignore`-да жазылған. Орта міндетті емес, бірақ бұл — қабылданған тәжірибе.

## 2. Сервер және деректер жолы
`python app.py` Flask-ты іске қосады: `@app.get(...)` мекенжайды функцияға байлайды, `app.run()` 5000 портты тек сіздің компьютеріңізде (127.0.0.1) ашады.

**http://127.0.0.1:5000 ашқанда:**
1. Браузер `GET /` жібереді.
2. Flask `index()` функциясын шақырады.
3. `send_from_directory` `blackout.html` файлын оқып, жауап ретінде жібереді (код 200).
4. Браузер HTML-ді оқып, `<script src="…three.min.js">` үшін cdnjs-ке бөлек сұраныс жібереді.
5. Ішіндегі скрипт орындалып, ойын басталады.

**Содан кейін ойын серверге қарамайды.** Лабиринт, күзетші, A*, CSP, Байес сүзгісі — бәрі браузерде есептеледі. Сондықтан файлды Python-сыз ашса да ойын жүреді.

**API** (`/api/puzzle`, `/api/maze`) демонстрация үшін. `GET /api/puzzle?seed=3` сұранысы:
1. `request.args.get("seed", type=int)` мекенжайдан параметрді санға айналдырады.
2. `generate_puzzle(seed)` шақырылады.
3. `jsonify` Python сөздігін JSON мәтініне айналдырып жібереді.
4. `demo_client.py`-да `requests.get(url, params, timeout=10)` жауап алады, `.json()` оны қайта сөздікке айналдырады.

Қате енгізу (мысалы `n=8`): `maze.generate` `ValueError` тастайды, сервер `try/except`-пен ұстап, `400` және қате мәтінін қайтарады. Сервер қосылмаса, `requests` `ConnectionError` тастайды, скрипт түсінікті хабар шығарады.
Дерекқор жоқ, сервер ештеңе сақтамайды: әр сұраныс бәрін қайта жасайды. `secret` API-де тек демонстрация үшін беріледі; нақты ойында оны жасырады.

## 3. Код қалай жұмыс істейді

### Лабиринт
Тор: 1 — қабырға. Бөлмелер тақ координаттарда. (1,1)-ден бастап кездейсоқ бағытқа 2 ұяшық секіреді, егер ол жер әлі қабырға болса, ортасындағы қабырғаны бұзады (`dy//2`). Бару керек жер жоқ болса, стек арқылы артқа қайтады (`for…else`). Нәтиже — циклсыз «мінсіз» лабиринт. Содан кейін 30 рет бір ғана өске жолы бар қабырғаны бұзып, айналма жолдар жасайды.

### A* (2-апта)
Кезекте `(f, g, ұяшық)`, мұндағы g — жүрілген жол, h — манхэттен қашықтығы (|dx|+|dy|). f=g+h ең кіші ұяшықты аламыз. `best` — әр ұяшыққа белгілі ең жақсы g, `came` — қайдан келдік, `closed` — ашылғандар.
Торда қадам 1 болғандықтан бұл эвристика асыра бағаламайды, сондықтан мақсат кезектен шыққанда жол **ең қысқа**. Тест оны BFS-пен салыстырады. Жол `came` бойынша мақсаттан артқа жиналады. `expanded` — ашылған түйін саны.

### CSP (3-апта)
Айнымалылар: A, B, C, D цифрлары, домен 0–9. `make_clues(secret)` құпия код үшін **ақиқат** барлық шарттарды жасайды (тақ/жұп, A>B, A+B=9, жалпы қосынды). `i=i` жазбасы lambda-ға цикл мәнін бекітеді, әйтпесе барлығы соңғы мәнді тексерер еді.
`solve` — **кері іздеу**: A, сосын B, C, D қояды; әр қадамнан кейін тек барлық айнымалысы қойылған шарттарды тексереді (`max(c.vars) > i or c.test(d)`). Шарт бұзылса, тармақ бірден тасталады — 10 000 нұсқаның бәрін аралау керек емес.
`generate_puzzle`: кездейсоқ код алып, `pool_size` шартты кездейсоқ таңдап, үміткер санын ең көп азайтатынын ашкөздікпен қосады — шешім біреу болғанша. Сәтсіз болса, кодты қайта таңдайды. Деңгей қиындаған сайын `pool_size` (ойында `p`) азаяды, таңдау нашарлайды, шарт көбірек керек.
Ойындағы «Код үміткерлері» — жиналған шарттар бойынша `solve(found).length`; A,B,C,D жанындағы цифрлар — қалған шешімдердегі мүмкін мәндер.

### Байес сүзгісі / HMM (7-апта)
Жасырын күй — күзетші білмейтін ойыншы ұяшығы. `ұяшық → ықтималдық` сөздігі (сенім) басында бірдей.
- **predict**: ойыншы орнында қалады (0,35) немесе кездейсоқ көршіге өтеді (0,65, тең бөлінеді). Ықтималдық лабиринт бойынша «жайылады».
- **update (көру)**: күзетші көрсе (`қашықтық < радиус` және `los` түзу көрінеді) — сенім бір ұяшыққа жиналады. Көрмесе — көру аймағындағы ұяшықтар ×0,01 («онда сен жоқсың»).
- **update (дыбыс)**: жүгірсең (3-деңгейден бастап жүрсең де), күзетші қашықтықтың шулы бағасын алады. Баға жақын ұяшықтар көбірек салмақ алады: `exp(-(d-obs)²/(2σ²))+0.02`. Бұл Байес формуласы: артқы ықтималдық ~ ықтималдық × алдыңғы, сосын қосындыны 1-ге келтіру.
- **Шешім**: күзетші ең ықтимал ұяшыққа (argmax) барады, жолды A* салады. Бос ұяшыққа жеткенде «көреді» және ықтималдық түседі, argmax басқа жерге ауысады — сондықтан ол бөлмелерді тінтіп жүргендей көрінеді.
- **Энтропия** — күзетшінің белгісіздігі: 0 бит — нақты біледі, ~8 бит — ештеңе білмейді.

### Ойын (JavaScript)
- `loop` секундына ~60 рет шақырылады: қозғалыс, таймер, камера, сурет салу.
- Тышқан: `pointerLock` тышқанды ойынға береді, `movementX/Y` `yaw` мен `pitch` бұрыштарын өзгертеді. Бұғатталмаса, батырманы басып тұрып қарауға болады.
- Қозғалыс: алға `(-sin yaw, -cos yaw)`, оңға `(cos yaw, -sin yaw)`. Соқтығысу төрт бұрыш бойынша (радиус 0,45), X және Z бөлек тексеріледі — қабырғаға жабыспай, бойымен сырғисың.
- Күзетші секундына 4 рет ойлайды (`aiTick`), әр кадрда қозғалады (`moveGuard`). Көріп, жақын болса — тікелей барады. Қашықтық 1-ден кем болса — ұсталдың.
- Жүгіру төзімділікті жейді; таймер нөлге жетсе — жеңіліс.
- three.js: қабырғалар бір `InstancedMesh` (тез), тұман мен камерадағы `PointLight` — «қол шам». Шағын карта — 2D canvas, тек зерттелген ұяшықтар; Tab — сенім картасы мен A* жолын қосады.
- Деңгейлер: `LV` массиві лабиринт өлшемін, күзетші жылдамдығын, көру қашықтығын, тұманды, дыбысты есту-естімеуді және `p` параметрін береді.

## 4. Тесттер не істейді
Тесттер файл, дерекқор немесе сервер **жасамайды**. Жадта лабиринт, жұмбақ, сүзгі құрып, алгоритмді шақырып, `assert` арқылы нәтижені тексереді. `pytest` `test_*.py` файлдарын табады, `test_` деп басталатын функцияларды орындайды. Лабиринт `seed`-пен жасалады, сондықтан нәтиже әр жолы бірдей.
1. A* жолының ұзындығы BFS-ке тең (оңтайлылық).
2. Жол дұрыс басталып аяқталады, ашылған түйін саны жол санынан аспайды.
3. Мақсат қабырға болса — жол бос (алгоритм құламайды).
4. 5 түрлі seed үшін CSP шешімі жалғыз және дұрыс.
5. Шартсыз 10 000 үміткер.
6. Генератор жалған шарт жасамайды.
7. Сүзгі қадамдарынан кейін ықтималдық қосындысы = 1.
8. Көрсе — сенім бір ұяшықта, энтропия 0.
9. Теріс дәлелден кейін көрінетін ұяшықтың ықтималдығы түседі.

Шектеу: тесттер тек Python нұсқасын тексереді. Ойынның JS нұсқасында бастапқы экранда 3 өзіндік тест бар (A* = BFS, CSP жалғыз шешім, ықтималдық қосындысы = 1). Ойынның ойнауға жарамдылығы (қиындығы, уақыт жететіні) тесттелмеген.

## GitHub және ойынды барлығына ашу (GitHub Pages)
Ойын — статикалық HTML, сондықтан Python-сыз GitHub Pages-те тегін жұмыс істейді. `docs/index.html` — ойынның көшірмесі, Pages осы папканы береді.
1. github.com-да аккаунт ашыңыз → New repository → аты `qairu-blackout`, Public, README қоспаңыз.
2. Жобаны жүктеңіз. Терминалмен:
   `git init` → `git add .` → `git commit -m "BLACKOUT"` → `git branch -M main` → `git remote add origin https://github.com/ЛОГИНІҢІЗ/qairu-blackout.git` → `git push -u origin main`.
   Терминалсыз: репозиторийде «uploading an existing file» → zip-ті АШЫП, ішіндегі файлдар мен папкаларды (docs, ai, tests, static…) сүйреп апарыңыз → Commit.
3. Settings → Pages → Source: «Deploy from a branch» → Branch: `main`, папка `/docs` → Save.
4. 1–2 минуттан соң сілтеме шығады: `https://ЛОГИНІҢІЗ.github.io/qairu-blackout/` — осыны README басына және есепке қойыңыз.
5. Жаңарту: `docs/index.html` пен `static/blackout.html` бірдей болуы керек; өзгерткенде екеуін де жаңартыңыз.

Ескерту: GitHub Pages тек ойынды береді. `app.py` (Flask API) онда жұмыс істемейді, оны компьютерде іске қосасыз.
API кілттері жоқ. Скриншоттар, әр қатысушының үлесі және AI Usage Declaration қосыңыз.
